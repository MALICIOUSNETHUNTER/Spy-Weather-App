# Spy Weather App 🌦️

A Python desktop weather application built using Tkinter and OpenWeatherMap API.

## Features

* Select Indian states and districts
* Real-time weather information
* Temperature details
* Feels like temperature
* Maximum and minimum temperatures
* GUI built with Tkinter
* Dynamic district dropdown system

## Technologies Used

* Python
* Tkinter
* Requests
* Pillow
* OpenWeatherMap API

## Future Improvements

* Better modern GUI
* Weather icons
* Humidity and wind speed
* Live weather animations
* Better error handling

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the app:

python main.py
